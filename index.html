How to play

Every card has four features: number (1, 2, 3), shape (diamond, oval, squiggle), color (red, green, purple) and shading (solid, striped, open). A set is three cards where, for each feature, all three cards are the same or all three are different.

Select three cards. A valid set is removed and replaced from the deck (+3 points). An invalid pick costs 1 point. If you can’t find a set, use Hint (−1) or add three more cards. The game ends when the deck is empty and no sets remain.
